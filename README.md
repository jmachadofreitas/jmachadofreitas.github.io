# Personal website

Hugo Extended **0.165.0**.

Clone and serve:

```bash
git clone --recurse-submodules https://github.com/jmachadofreitas/jmachadofreitas.github.io.git
cd jmachadofreitas.github.io
hugo server
```

If the theme is missing after cloning:

```bash
git submodule update --init --recursive
```
